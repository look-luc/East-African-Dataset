# Verifying literal translation of East African Languages
## Overall Scope
### Data files
In the **data** folder, there is just the data from the original dataset and experiment. There is a python script to get the individual lines of a language.
### Other files
This repo is to get a rough first draft for glossing later on. So the files that don't handle the data are to get the rough morphological boundaries of the languages.

The language families that will be used are the Bantu, Nilotic, and Cushitic
